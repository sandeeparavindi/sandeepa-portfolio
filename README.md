
# ✨ Sandeepa Ravindi | Personal Portfolio

A modern, responsive, and interactive personal portfolio showcasing my skills, projects, education, and journey in software engineering.

Designed with a sleek **Yellow & Black theme**, smooth animations, and a clean user experience.

## 🚀 Tech Stack

- ⚛️ React.js
- 🟨 JavaScript
- 🎨 Tailwind CSS
- ✨ Framer Motion
- ⚡ Vite

## 🌟 Features

- Fully responsive and modern UI
- Dark and Light Mode
- Smooth animations and transitions
- Interactive project showcase
- Skills and education sections
- Contact and social media links
- Downloadable CV
